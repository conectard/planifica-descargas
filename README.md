# Planifica para Windows

Descarga el instalador de **Planifica**, la app para docentes: aulas, calificaciones, asistencia y planificaciones.

**[⬇ Descargar Planifica para Windows](https://github.com/conectard/planifica-descargas/releases/latest/download/Planifica-Setup.exe)**

Windows 10 u 11 (64 bits). Abre el instalador, sigue los pasos y entra con tu cuenta de Planifica.
Si Windows muestra «Windows protegió su PC», toca **Más información → Ejecutar de todas formas**.
